# 強度行動障害 支援ナビ PWA版

## 主な機能
- iPhone向けPWA風UI
- 「ホーム画面に追加」対応
- 場面別対応：こだわり、感覚過敏、パニック、自傷、他害、大声、予定変更、待ち時間
- 利用者ごとの特性メモ
- 利用者ごとの支援手順書
- 支援手順書の印刷 / PDF保存
- ABC記録
- 支援チェック
- オフライン利用のためのService Worker

## iPhoneでの利用
Webサーバー上にこのフォルダ一式を置き、Safariで `index.html` を開いてください。
共有 →「ホーム画面に追加」でアプリのように起動できます。

※ローカルファイルを直接開く場合は、Service WorkerやPWA機能が動作しないことがあります。

## データ保存
利用者情報、支援手順書、ABC記録は localStorage に保存します。
業務で実運用する場合は、認証・暗号化・アクセス権限・バックアップ・監査ログ等を備えた安全な保存方式に変更してください。

## 内容について
国立障害者リハビリテーションセンターの「強度行動障害支援者研修資料」にある、
障害特性の理解、構造化、コミュニケーション、行動の背景と捉え方、
支援手順書、記録に基づく支援の評価、組織的アプローチ等を参考に、
学習・支援補助向けに再構成しています。
